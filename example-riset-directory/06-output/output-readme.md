## 2. Penjelasan Hasil Interpretasi Data

### A. Analisis Parameter Efisiensi: Durasi Checkout (Pair 1)
1. **Nilai Perbedaan Rata-rata (Mean Paired Differences):** 
   Nilai Mean sebesar **5.829** menunjukkan bahwa rata-rata waktu transaksi menggunakan alur GrabFood lebih lambat sekitar **5,8 detik** dibandingkan dengan GoFood. Dengan kata lain, alur kerja *Single-Screen* (GoFood) sukses memotong waktu tunggu transaksi responden.
2. **Nilai Signifikansi (Sig. 2-tailed):** 
   Didapatkan nilai **Sig. = 0.000**. Karena nilai probabilitas ini jauh lebih kecil dari standar alpha penolakan (0.000 < 0.05), maka Hipotesis Nol (H0) ditolak secara mutlak.
3. **Kesimpulan:** 
   Perbedaan durasi checkout antara kedua aplikasi di atas adalah nyata dan signifikan secara statistik pada tingkat kepercayaan 95%. Alur halaman tunggal terbukti memberikan dampak akselerasi waktu pengerjaan tugas secara riil bagi responden.

### B. Analisis Parameter Akseptabilitas: Total Skor SUS (Pair 2)
1. **Nilai Perbedaan Rata-rata (Mean Paired Differences):** 
   Nilai Mean sebesar **-25.7143** (bernilai negatif) mengindikasikan bahwa rata-rata skor kepuasan kuesioner SUS untuk GrabFood secara masif lebih rendah sebesar **25,7 poin** dibandingkan dengan total rata-rata skor SUS GoFood.
2. **Nilai Signifikansi (Sig. 2-tailed):** 
   Diperoleh nilai **Sig. = 0.000**. Berdasarkan aturan pengambilan keputusan statistik (0.000 < 0.05), Hipotesis Nol (H0) resmi ditolak dan Hipotesis Alternatif (Ha) diterima.
3. **Kesimpulan:** 
   Kesenjangan penilaian kenyamanan subjektif antarmuka ini teruji sangat signifikan. Degradasi kepuasan pengguna pada model antarmuka bertahap (*Multi-Step*) bukan terjadi karena unsur kebetulan semata, melainkan akibat adanya friksi kognitif navigasi halaman yang lebih tinggi.
