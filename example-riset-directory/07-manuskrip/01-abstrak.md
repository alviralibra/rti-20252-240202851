# Abstrak / Abstract

**Abstrak**  
Penelitian ini didorong oleh urgensi untuk mengatasi tingginya beban kognitif (cognitive load) yang dialami pengguna Generasi Z saat berinteraksi dengan antarmuka transaksional pada aplikasi pesan-antar makanan. Fenomena lapangan menunjukkan adanya hambatan mental berupa keraguan pengguna yang tecermin dari durasi pengerjaan tugas (Time on Task) yang melebihi 15 detik pada halaman konfirmasi. Penelitian ini bertujuan untuk melakukan analisis perbandingan secara empiris dan head-to-head antara model alur Single-Screen (GoFood) dan model Multi-Step (GrabFood) untuk menentukan paradigma desain yang paling efisien. Metodologi yang diterapkan adalah eksperimen terkontrol dengan desain Within-Subject terhadap 35 responden mahasiswa pengguna aktif. Data dikumpulkan menggunakan metrik objektif berupa durasi detik penyelesaian tugas melalui screen recording, serta metrik subjektif menggunakan kuesioner System Usability Scale (SUS) dengan teknik counterbalancing untuk mengeliminasi learning effect. Hasil analisis inferensial menggunakan Paired Samples t-test menunjukkan bahwa alur Single-Screen secara signifikan memangkas waktu transaksi dengan nilai perbedaan rata-rata sebesar 5,829 detik lebih cepat dibandingkan model Multi-Step (t-hitung = 33,068, p < 0,001). Sejalan dengan itu, skor akseptabilitas sistem (SUS) pada model Single-Screen unggul mutlak dengan selisih rata-rata 25,7143 poin lebih tinggi (t-hitung = 10,948, p < 0,001). Temuan ini membuktikan secara empiris bahwa integrasi elemen transaksi satu halaman efektif mereduksi cognitive load bagi pengguna Generasi Z..

**Kata Kunci:** Efisiensi Kognitif, GoFood, GrabFood, Single-Screen vs Multi-Step, Generasi Z[cite: 1].

**Abstract**  
*This study was driven by the urgency to address the high cognitive load experienced by Generation Z users when interacting with transactional interfaces on food delivery applications. Field phenomena indicate mental barriers in the form of user hesitation, reflected in a task completion duration (Time on Task) exceeding 15 seconds on the confirmation page. This study aims to conduct an empirical, head-to-head comparative analysis between the Single-Screen flow model (GoFood) and the Multi-Step model (GrabFood) to determine the most efficient design paradigm. The methodology applied was a controlled experiment with a Within-Subject design on 35 active student respondents. Data were collected using an objective metric of task completion duration in seconds via screen recording, and a subjective metric using the System Usability Scale (SUS) questionnaire, applying counterbalancing techniques to eliminate the learning effect. Inferential analysis using the Paired Samples t-test showed that the Single-Screen flow significantly reduced transaction time with a mean difference of 5.829 seconds faster than the Multi-Step model (t-value = 33.068, p < 0.001). In line with this, the system usability score (SUS) for the Single-Screen model was absolutely superior, with a mean difference of 25.7143 points higher (t-value = 10.948, p < 0.001). These findings empirically prove that integrating transaction elements onto a single page effectively reduces cognitive load for Generation Z users..*
