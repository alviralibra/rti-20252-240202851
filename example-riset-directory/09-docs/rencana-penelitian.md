# Rencana Penelitian: Analisis Usability dan Efisiensi Kognitif Alur Checkout Food Delivery

## 1. Ringkasan

| Item | Keterangan |
|---|---|
| **Judul** | Analisis Perbandingan Efisiensi Kognitif dan Kepuasan Pengguna pada Alur Checkout Model Single-Screen (GoFood vs GrabFood) pada Generasi Z |
| **Peneliti** | Alvira Libra Ramadhani |
| **Target Publikasi** | Sinta 2 (Jurnal RESTI/Telematika) atau Scopus Q3–Q4 |
| **Metodologi & Alat** | Usability Testing, System Usability Scale (SUS), Google Form, Figma, Python/SPSS |
| **Masalah** | Alur *checkout* padat vs sekuensial memicu *cognitive load* tinggi dan potensi *cart abandonment* bagi Gen Z |
| **Solusi/Fokus** | Evaluasi komparatif empiris model *Single-Screen* (GoFood) vs *Multi-Step* (GrabFood) via metrik kuantitatif |

## 3. Catatan Ringkas

Dokumen ini berfungsi sebagai indeks utama perencanaan riset UI/UX. Semua detail teknis pengujian operasional variabel, instrumen 10 pertanyaan kuesioner SUS, rekaman log *recording* untuk *Task On Time* (TOT), hingga skrip otomatisasi analisis data kuantitatif dicatat dan diperbarui secara berkala pada berkas `tahap-N-*.md` terkait demi menjaga ketertelusuran (*traceability*) artefak akademik.
